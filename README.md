# CarBG API Documentation

CarBG provides AI-powered automotive image and video processing APIs.

## API Base URL

```text
https://api.carbg.ai
```

## Authentication

All authenticated API requests require an API key:

```http
API-KEY: YOUR_API_KEY
```

## APIs

### Image APIs

* [Replace Car Image Background](image/replace-background/README.md)



## Supported Languages

Code examples are available for:

* cURL
* Python
* Node.js
* Java
* Kotlin
* .NET / C#
* Swift

## Request Format

Most image and video processing APIs use:

```http
multipart/form-data
```

## API Version

The current recommended API version is:

```text
v1.0
```
